# finance-design-system
A solução é uma camada B2B2C de autonomia financeira para startups, MEIs e pequenos negócios, operada via parceiros. Ela ajuda a tomar decisões sob incerteza e a separar contas pessoais e empresariais sem registros manuais. Para isso, combina Open Finance PJ, projeção de sobrevida do caixa (runway) e intervenções contextuais no momento da decisão.
